# INNOCECT Store — Shopifyテーマ

INNOCECT 公式オンラインストア用の Shopify テーマです（Online Store 2.0）。プロテイン・アミノ酸・食物繊維を販売するストア向けに作っています。

> この公開リポジトリには、テーマのコードだけを置いています。価格や仕入れ先などの情報は含めていません。文中の `[価格]` `[◯]` `[入力]` などは、実際の値に置き換える前提の仮の値です。

## 入っているページ

- トップ（ヒーロー、カテゴリ・目的から探す、ランキング、おトクな買い方、よくある質問 など）
- 商品一覧（タブ、絞り込み、並び替え、比較表）
- 商品詳細（7商品それぞれの専用テンプレート＋汎用テンプレート）
- カート、検索、固定ページ（はじめての方へ／おトクな買い方）、会員ページ、404、ブログ

## 主な機能

- **商品ページ：**
  - フレーバー選択に合わせて価格・URL・画像が切り替わります。
  - 定期便と1回購入を切り替えられ、お届け周期も選べます。
  - 数量を変えると合計と、まとめ買い割の案内が変わります。
  - カートに入れたあとの通知、スマホの追従カートボタン、近日発売のフレーバー表示があります。
- **カート：** 送料無料までの残り、まとめ買い割の案内と追加提案、商品ごとの定期便切り替え、数量変更・削除、クーポン入力。どれもページを再読み込みせずに動きます。
- **価格の自動計算：** 「1杯あたり約◯円」「定期便なら◯円」などの文言は、商品の価格とメタフィールド（1袋あたりの杯数）から計算します。価格を変えても文言を直す必要はありません。
- **テーマ設定：** 色、数字のフォント、送料無料の金額、定期便の割引率、まとめ買い割の点数と割引率、フレーバーの色を変えられます。
- **テーマエディタ：** セクションを編集して再描画されても、ボタンなどが動き続けます。

割引そのもの（まとめ買い割など）は Shopify の管理画面で設定します。テーマは案内を表示するだけです。

## フォルダ構成

Shopify の標準のフォルダ構成です。このまま Shopify の GitHub 連携でつなげられます。

| フォルダ | 中身 |
|---|---|
| `layout/` | 共通の枠（`theme.liquid`） |
| `sections/` | ページの部品（`main-product`＝購入ボックス、`main-cart`＝カート、商品LPの各ブロック など） |
| `snippets/` | 小さな部品（商品カード、アイコン、価格の文言を計算する `tokens` など） |
| `templates/` | ページごとの構成（JSON） |
| `config/` | テーマ設定 |
| `assets/` | `base.css`（スタイル）、`theme.js`（動き。外部ライブラリなし） |
| `locales/` | 文言（日本語・英語） |

## 導入の流れ（概要）

1. テーマをアップロードするか、GitHub 連携で接続します。
2. 商品のメタフィールドを2つ作ります。
   - `innocect.servings`（整数）：1袋あたりの杯数・回数
   - `innocect.serving_label`（単一行テキスト）：表示の言い回し。例：「1杯（30g）あたり」
3. 商品を登録し、商品ごとに `product.◯◯` テンプレートを割り当てます。
4. コレクション（`protein` `amino` `fiber` と、目的別のコレクション）、ページ、メニューを作ります。
5. 定期購入アプリを入れて販売プランを作り、まとめ買い割を自動割引で設定し、送料を設定します。
6. テーマ設定と各セクションに残っている `[ ]` の仮の値を埋めます。

## 開発メモ

- `snippets/tokens.liquid`：文言の `{per}`（1杯あたり）、`{per_sub}`（定期便の1杯あたり）、`{price}`、`{month}` などを、価格から計算して置き換えます。
- `assets/theme.js`：Cart Ajax API（`/cart/add.js`・`/cart/change.js`・`/cart/update.js`）と Section Rendering API を使います。`window.INNOCECT.init(要素)` でセクション単位に初期化できます。
- `shopify theme check` でエラー0件を確認済みです。
